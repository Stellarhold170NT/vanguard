## Lessons (CAN)

1. The broker blocks `>`/`>>`/`tee` into workspace files; background work goes through a script
   written with `sandbox_write_file` and launched with `sh <script>` (log to /tmp), polled with a
   bounded kill -0 loop — no unbounded waits (process amendment 2).
2. `xargs … | wc -l` under-reports when xargs splits into batches (last-batch total only) — use
   `xargs -0 cat | wc -l` for tree LOC. Caught by cross-checking against the generator's own count.
3. Litterbox relay still works (24h) but is time-rotting infrastructure (w3-07 lesson confirmed);
   sha256 on both sides every round remains mandatory. Sandbox had outbound network for apk/Go
   modules — no vendoring needed.
4. Golden snapshots normalize durations via `<duration>`; any change to the default pretty header
   shape requires `make golden-update` + review (done; §2.1 contract).

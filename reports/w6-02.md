## 2. Thiết kế — quyết định chính

1. **`scratch` thay vì distroless**: binary là ELF musl **fully static** (zig-cc, w6-01 recipe) nên image không cần libc/shell/ca-cert (scan không gọi mạng — đọc file + parse). Kết quả đo được: **1 file duy nhất** trong rootfs, 8.7 MiB. Distroless (≈2-3 layer + base certs) chỉ cần nếu sau này thêm TLS/OS-release detection — YAGNI ở v0.1.
2. **CGO_ENABLED=1 + `CC="zig cc -target x86_64-linux-musl"`** — không phải `CGO_ENABLED=0` (brief nhắc "đừng phụ thuộc glibc"): w6-01 đã root-cause rằng tree-sitter java grammar là cgo, `CGO_ENABLED=0` fail `build constraints exclude all Go files`. Đường zig-musl cho static ELF — chính recipe đã verify 6/6 targets của w6-01 (§2 đó).
3. **Canary trong builder** (`&& /out/vanguard version` sau `go build`): binary không chạy được trên builder musl-only = image sẽ hỏng → fail ở build, không tới `docker run`. Chạy thật: canary in `vanguard 0.1.0-dev (commit unknown, built unknown)`.
4. **zig pin bằng ARG + sha256**: `ZIG_SHA256=70e49664…` kiểm trong build (`/tmp/zig.tar.xz: OK`) **và** đối chiếu index chính thức ziglang.org trước khi build (§3.1) — build reproducible, không tin network ngầm.
5. **Build identity qua ARG** `VERSION/COMMIT/DATE` (w2-06 contract): default degrade như `go build` thường; tag-build stamp bằng `--build-arg` (chỉ dẫn đã ghi vào install.md §2). **Không ARG nào nhận secret** — layer audit xác nhận (§3.3).
6. **`.dockerignore` là guarantee cấu trúc**: context chỉ mang module sources; testdata/docs/reports/VCS không bao giờ tới daemon → không thể lọt layer nào. Ghi rõ trong header file.
7. **Compose demo `read_only: true` + mount `:ro`**: scanner chỉ đọc /src, report ra stdout — demo chứng minh cả 2 tính chất, không cần viết thêm gì.
8. **Exit codes trong docs theo code, không theo phỏng đoán**: `internal/engine/run.go:211` — `2` = tool error; `1` = có ≥1 finding ERROR; còn lại `0` (kể cả WARN-only). Verify thực tế 2 lần: scan stub-repo (1 WARN) → EXIT=0; `check` in "clean — 0 ERROR, 1 WARN … (exit 0)". Draft đầu viết sai ("exits 1 when it finds violations") → **đã sửa** trong `15cacd9`.

## 9. CAN LESSONS (Amendment 1)

1. **Broker ENOSPC**: `sandbox_git_clone`/`sandbox_create` → HTTP 500 `ENOSPC: no space left on device`. Khắc phục bằng cách **reuse live sandbox session** có sẵn thay vì tạo mới; `sandbox_write_file` nhỏ vẫn hoạt động. Lesson: khi broker đầy, đừng retry tạo workspace — reuse session đang sống.
2. **Không có `sandbox_expose_port` / HTTP-bridge cho artifact**: `sandbox_save_file(url)` không fetch được từ mạng sandbox (thử `127.0.0.1:8046` và `172.17.0.11:8046` đều fail) → protocol chunked base64 qua output-spill là kênh chuyển binary duy nhất; scale được lên 400 KB/chunk, gom 9 chunk vào 1 lệnh bằng marker, verify md5 từng chunk.
3. **Container dind thiếu tool**: `make` và applet `busybox httpd` không có sẵn → `apk add --no-cache make`, dùng `python3 -m http.server` thay thế. Lesson: check `command -v` trước khi giả định tool tồn tại.
4. **Shell redirect bị fence** trong `sandbox_shell` (command string) → mọi ghi file phải qua script file (`sandbox_write_file`) hoặc `sandbox_write_file` trực tiếp; script body không bị fence.
5. **goreleaser chạy trên cây nào thì commit đó**: lần thử cũ build ở branch head (8ec69f7) sinh metadata sai commit; bắt buộc verify `metadata.json.commit` + tree hash trước khi coi release build là hợp lệ. Đã thêm vào checklist: `metadata.json.commit == merge commit của main == tag^{}^`.
6. **Tag phải nằm trên merge commit của main** (SOP) — tag cũ ở branch head đã bị phát hiện nhờ `git ls-remote --tags origin` (chưa push) rồi xoá/tạo lại; luôn verify tag chưa published trước khi di chuyển.
